# 📚 AI Study Planner

A beginner-friendly study planning and tracking application built using Python and Streamlit.

## Features
- Create personalized study plans
- Organize subjects and study topics
- Track study sessions using a timer
- Record actual study time
- View daily and subject-wise analytics
- Track daily study goals and progress
- Download study plan reports as CSV
- Download actual study reports as CSV
- Maintain study history

## Technologies Used
- Python
- Streamlit
- Pandas
